# build-business-objectives-model

## Overview
This skill guides the agent to extract and construct a **Business Objectives Model (BOM)** as defined in *Visual Models for Software Requirements*. The BOM sits at the very top of the Requirements Modeling Language (RML) hierarchy. It ensures that before any features are designed, the team agrees on the exact Business Problems, the quantifiable Business Objectives, and the overarching Product Concept.

## Usage
Trigger this skill when given raw vision documents, stakeholder meeting notes, or project charters that need to be grounded in measurable business value.

```markdown
Use the `build-business-objectives-model` skill to extract the BOM from this project kickoff transcript.
```
