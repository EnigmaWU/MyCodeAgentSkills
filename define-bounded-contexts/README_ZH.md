# define-bounded-contexts

## 概述 (Overview)
使用时间/地点/人员: 软件架构师、领域专家或代理人在拆分单体架构或设计微服务架构时。
方法: 使用此技能将系统划分为子域(核心、支撑、通用)，并使用上下文映射模式映射限界上下文之间的集成契约。
原因: 单体模型会失败，因为单词在不同的上下文中意味着不同的东西。库存中的"产品"是一个物理盒子；电子商务中的"产品"是一个目录列表。明确定义限界上下文可以防止大泥球架构。

触发此技能以执行定义的工作流。有关特定的触发器和输入，请参见 `SKILL.md`。
