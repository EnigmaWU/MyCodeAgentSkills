# facilitate-example-mapping

## Overview
This skill guides the agent to facilitate an **Example Mapping** workshop. Example Mapping is a fast, structured, low-tech way to explore a User Story before development starts. It forces the team to identify the Business Rules, concrete Examples that prove those rules, and open Questions that block progress.

## Usage
Trigger this skill during Backlog Refinement, Sprint Planning, or dedicated "Three Amigos" sessions when a User Story is too vague to estimate or implement.

```markdown
Use the `facilitate-example-mapping` skill to break down this "Calculate Tax" User Story.
```
