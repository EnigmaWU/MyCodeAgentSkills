# facilitate-example-mapping

## 概述 (Overview)
使用时间/地点/人员: 业务分析师、产品负责人或代理人领导待办事项梳理或“Three Amigos”会议时。
方法: 使用此技能将用户故事分解为业务规则（蓝色），具体示例（绿色）和未决问题（粉色）。
原因: 非结构化的对话会漫无目的并遗漏边缘情况。Example Mapping提供了一个视觉上的广度优先约束。

## 使用方法 (Usage)
触发此技能以执行定义的工作流。有关特定的触发条件和输入，请参阅 `SKILL.md`。
