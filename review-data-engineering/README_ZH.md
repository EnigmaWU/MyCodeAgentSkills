# review-data-engineering

## 概述 (Overview)

WHEN/WHERE/WHO: 当需要把一个现有仓库、项目、平台、管道或架构作为数据工程项目来评审时，使用此技能。触发语包括 "review data engineering"、"data engineering lifecycle assessment"、"audit this data pipeline"、"review our data stack" 和 "assess this project as a data platform"。

HOW: 此技能会发现项目证据，映射数据工程生命周期，评审跨阶段的 undercurrents，按证据与风险分类发现，并输出可执行的生命周期评审建议。

WHY: 现有项目常把数据工程责任隐藏在应用代码、notebook、工作流、基础设施和文档中。生命周期评审可以让来源、存储、摄取、转换、服务、安全、运维和成本风险变得可见。

## 使用方法 (Usage)

适用于：

- 将仓库作为数据工程项目进行评审。
- 评估数据管道的生产就绪度。
- 审查数据来源、存储、摄取、转换和服务职责。
- 评审 DataOps、编排、数据管理、安全/隐私和成本风险。
- 输出 findings-first 的数据工程评审建议。

不要将它用于单独的图表评审、数据字典抽取、通用代码评审，或从零设计新数据平台，除非请求明确要求评审现有项目。
