# skill-common

Shared common contract for every skill in this repository. Skills load this package at activation via their `## Common Contract (Load First)` section, so the shared spine, frontmatter rules, Optimization Readiness contract, anti-patterns, and the Review In Mind (ReviewInMindGenie) loop live in one place instead of being duplicated.

See [SKILL.md](./SKILL.md) for the contract and `details/` for the shared building blocks.
