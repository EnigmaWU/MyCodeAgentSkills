# One More Thing — Standard Closing Rule

Every skill MUST apply this rule before starting real work:

> If anything is unclear, missing, or conflicting, stop and ask the user before proceeding.

The `## One More Thing` section is a **pre-flight checkpoint**, not a sign-off note. It is placed after `## Constraints` and **before `## How`** so the agent asks about anything unclear or conflicting before it starts executing the workflow. If a skill needs a domain-specific warning, it keeps its own `## One More Thing` text, but the standard rule still applies as the default.
