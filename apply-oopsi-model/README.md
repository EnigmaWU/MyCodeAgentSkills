# apply-oopsi-model

## Overview
This skill guides the agent to use the **OOPSI** model (Outcome, Outputs, Process, Scenarios, Inputs) created by Jenny Martin and Pete Buckney. OOPSI is a collaborative discovery practice that works backwards from the highest-value business outcome down to the granular data inputs needed to test it.

## Usage
Trigger this skill when breaking down a complex workflow or user journey, ensuring that you don't miss the underlying business value amidst the technical details.

```markdown
Use the `apply-oopsi-model` skill to break down the "Book a flight with points" feature.
```

## Structure
- [SKILL.md](./SKILL.md): The core workflow for working backward through the OOPSI layers.
- [details/oopsi-framework.md](./details/oopsi-framework.md): A template detailing the 5 layers of the OOPSI model.
