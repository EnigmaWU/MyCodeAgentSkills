# apply-fundamentals-of-data-visualization

## 概述 (Overview)
使用时间/地点/人员: 数据分析师、研究人员、产品团队或代理人在设计或审查可视化图表时。
方法: 使用此技能按分析问题选择图表，应用感知友好的视觉编码，完善配色、标注、上下文与叙事表达。
原因: 错误的图表选择和视觉编码会误导判断，掩盖关键洞察。

## 使用方法 (Usage)
当你需要重构图表可读性、提升可访问性、或确保图表表达准确时触发此技能。
