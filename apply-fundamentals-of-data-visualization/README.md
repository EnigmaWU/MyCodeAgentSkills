# apply-fundamentals-of-data-visualization

## Overview
This skill converts practical visualization principles from Fundamentals of Data Visualization into an execution workflow for agents and teams.

It helps you:
- choose chart types by analytical task,
- map data to perception-safe encodings,
- design charts for readability and accessibility,
- avoid misleading visual patterns,
- improve narrative clarity in reports and presentations.

## Usage
Trigger this skill when you need to design, review, or refactor visualizations.

Example:

Use the apply-fundamentals-of-data-visualization skill to redesign these dashboard charts for clarity and accessibility.
