# Visualization Quality Checklist for Feature Trees

Use this checklist after generating the Mermaid mindmap.

## 1. Structural Readability
- Verify L1 branches are visually distinct and not overcrowded.
- Verify L2 and L3 labels are short noun phrases.
- Verify the tree can be understood without zooming excessively.

## 2. Visual Encoding Discipline
- Verify color is optional enhancement, not required for meaning.
- Verify category colors (if used) are limited and distinguishable.
- Verify no decorative style is added without communication value.

## 3. Label and Context Clarity
- Verify node labels use domain language stakeholders understand.
- Verify ambiguous labels are clarified or split.
- Verify the root node expresses the product concept clearly.

## 4. Cognitive Load Control
- Verify one mindmap communicates one primary scope message.
- Verify very large trees are split by domain/module when needed.
- Verify sparse branches are reviewed for potential missing sibling features.

## 5. Accessibility and Portability
- Verify structure is understandable in grayscale or plain text exports.
- Verify Mermaid output renders correctly in the target documentation platform.
- Verify references to supporting artifacts are available when needed.
