# test-case-with-readme

Use when: the user creates a new test case, plans to write a test, or asks to generate a readme for an existing test. Helps with: planning and documenting test files with structured purpose, status, coverage, and manual steps. Applies to: any test creation workflow or existing test files like .py, .cxx, etc.
