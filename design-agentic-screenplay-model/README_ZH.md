# design-agentic-screenplay-model

## 概述 (Overview)
WHEN/WHERE/WHO: [Scheduling: 当AI智能体或架构师设计多智能体或自治系统的核心推理和执行循环时使用。]
HOW: [Structural: 使用此技能严格按照参与者（智能体）、能力（工具）、任务（提示/链）和交互（工具执行）来定义系统。]
WHY: [Scheduling: 整体提示和非结构化的工具使用会导致推理漂移。Screenplay模式强制智能体行为具有确定性和可组合性。]

## 使用方法 (Usage)
触发此技能以执行定义的工作流。有关特定的触发器和输入，请参见 `SKILL.md`。

## 结构 (Structure)
- [SKILL.md](./SKILL.md): 技能的核心工作流和定义。
