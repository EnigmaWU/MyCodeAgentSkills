# task-commit-trigger

## Overview
Use when: a task is just completed. Helps with: auto triggering or noticing developer "shall we commit just completed work?", and generating a structured WHAT/HOW/WHY commit message. Applies to: git repositories and conversation context.

Trigger this skill to execute the defined workflow. See `SKILL.md` for specific triggers and inputs.
