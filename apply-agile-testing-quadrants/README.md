# apply-agile-testing-quadrants

## Overview
This skill guides the agent to apply the Agile Testing Quadrants (introduced by Brian Marick, popularized by Lisa Crispin and Janet Gregory in *Agile Testing*) to structure a comprehensive test strategy. It ensures that testing isn't just focused on automated developer tests (unit tests) or manual UI testing, but rather provides a balanced approach covering four distinct quadrants: Q1 (Technology/Support), Q2 (Business/Support), Q3 (Business/Critique), and Q4 (Technology/Critique).

## Usage
Trigger this skill when reviewing a feature, writing an acceptance criteria document, or defining a test strategy for a sprint.

```markdown
Use the `apply-agile-testing-quadrants` skill to design a testing strategy for this new feature.
```
