# comment-alive-test-driven-development

## 概述 (Overview)
使用场景: 从头开始编写新测试，为新功能或模块设计验证，应用CaTDD，以及通过注释驱动设计启动新测试文件。有助于: 使用CaTDD方法创建结构化的测试文件，包含US/AC/TC设计，基于优先级的测试分类，以及适合LLM的验证注释。适用于: 任何语言中针对单元测试、系统测试和用户测试的新测试文件。
