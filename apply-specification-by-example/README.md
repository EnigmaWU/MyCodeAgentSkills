# apply-specification-by-example

## Overview
This skill translates the Specification by Example approach into an executable workflow for AI agents and delivery teams.

It helps teams:
- Derive feature scope from business goals
- Collaborate on clear, concrete examples
- Convert examples into executable validation
- Maintain living documentation that stays current

## Usage
Use this skill when you need better requirement clarity, acceptance criteria quality, and faster feedback loops.

Example trigger:

Use the apply-specification-by-example skill to define executable acceptance criteria for this feature.

## Structure
- [SKILL.md](./SKILL.md): Core process workflow, constraints, and validation rules
- [details/specification-by-example-checklist.md](./details/specification-by-example-checklist.md): Practical checklist and red flags for day-to-day execution

## Notes
This skill emphasizes process and collaboration over tool-first adoption.
