# apply-specification-by-example

## 概述 (Overview)

使用时间/地点/人员: 产品负责人、业务分析师、测试、开发或智能体在需求容易产生歧义、返工较多时使用。
方法: 通过业务目标驱动范围，使用协作示例定义行为，执行自动化验证，并持续产出活文档。
原因: 降低沟通偏差和返工成本，让需求、验证与交付保持一致。

## 使用方法 (Usage)

当你需要把验收标准变得可执行、可验证、可持续维护时触发此技能。

## 结构 (Structure)

- [SKILL.md](./SKILL.md): 技能核心流程、约束与验证规则
- [details/specification-by-example-checklist.md](./details/specification-by-example-checklist.md): 实操检查清单与常见红旗
